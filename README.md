# Биржа обмена лагерями — API

Демо-версия API-сервиса биржи, на которой участники Школы Фонда Потанина обмениваются распределёнными лагерями, а фонд согласует обмены. Учебный проект по курсу «Системный анализ и разработка сложных информационных систем» (НИУ ВШЭ, магистратура HCI, 2026). Это не официальный сервис фонда.

**Swagger UI:** http://109.123.242.26:8000/docs
**OpenAPI-спецификация:** [`docs/openapi.yaml`](docs/openapi.yaml), на стенде — http://109.123.242.26:8000/openapi.json

Лагеря — настоящий список сезона 2026 (63 лагеря, даты перенесены на 2027 год). Участники и сотрудники вымышленные. Данные хранятся в памяти, `POST /api/v1/demo/reset` возвращает стенд в исходное состояние.

## Методы

| Метод | Путь | Кто вызывает | Что делает |
|---|---|---|---|
| GET | `/api/v1/camps` | все | Каталог лагерей со спросом: сколько хотят уйти и сколько попасть |
| GET | `/api/v1/camps/{camp_id}/roster` | команда лагеря, кураторы, согласующий | Актуальный состав лагеря; поля зависят от роли |
| GET | `/api/v1/me` | все | Текущий пользователь: лагерь, заявка, активный обмен |
| PUT | `/api/v1/me/request` | участник | Создать или изменить заявку (до 5 лагерей по приоритету); сразу запускает подбор |
| DELETE | `/api/v1/me/request` | участник | Отозвать заявку |
| GET | `/api/v1/me/notifications` | все | Уведомления, отправленные во ВКонтакте или на email |
| GET | `/api/v1/swaps` | все | Обмены, доступные пользователю; фильтр по статусу |
| POST | `/api/v1/swaps` | участник | Оформить обмен, о котором договорились сами |
| GET | `/api/v1/swaps/{swap_id}` | участники обмена, фонд, команды лагерей | Карточка обмена с журналом действий |
| PATCH | `/api/v1/swaps/{swap_id}/members/me` | участник обмена | Согласиться или отказаться |
| POST | `/api/v1/swaps/{swap_id}/decision` | согласующий | Согласовать или отклонить (с комментарием) |
| GET | `/api/v1/exports/approved-swaps.csv` | согласующий, куратор | Выгрузка согласованных обменов |
| POST | `/api/v1/matching/runs` | куратор, согласующий | Запустить подбор вручную (тот же обработчик, что по расписанию) |
| POST | `/api/v1/demo/reset` | все | Сбросить демо-данные |

## Сценарий проверки: обмен по цепочке из четырёх человек

Анна, Борис и Виктория уже подали заявки, но парного обмена ни для кого нет. Заявка Григория замыкает цепочку Кижи → Валдайский → Забайкальский → Пасвик.

```bash
API=http://109.123.242.26:8000/api/v1
curl -X POST $API/demo/reset

# 1. Григорий хочет в Кижи — сервис подбора сразу находит цепочку (смотрите active_swap_id)
curl -X PUT $API/me/request -H "X-User-Id: p004" -H "Content-Type: application/json" -d '{"wishes": [8, 17]}'

# 2. Все четверо соглашаются (после сброса стенда это обмен №14 — он же в active_swap_id)
for u in p001 p002 p003 p004; do
  curl -X PATCH $API/swaps/14/members/me -H "X-User-Id: $u" -H "Content-Type: application/json" -d '{"response": "accepted"}'
done

# 3. Согласующий одобряет — лагеря меняются у всех четверых сразу
curl -X POST $API/swaps/14/decision -H "X-User-Id: approver1" -H "Content-Type: application/json" -d '{"decision": "approve"}'

# 4. Кэмп-лидер видит обновлённый состав Кижей и получил уведомление
curl $API/camps/8/roster -H "X-User-Id: leader1"
curl $API/me/notifications -H "X-User-Id: leader1"
```

Другие ветки: отказ участника (`{"response": "declined"}`) возвращает всех в подбор, и эта комбинация больше не предлагается; отклонение фондом без комментария возвращает 422.

## Как устроен подбор

`app/matching.py`: участники с активными заявками — вершины графа, ребро A → B означает «A хочет в лагерь B». Обмен — цикл длиной 2–4. Из найденных циклов выбирается набор без общих участников: сначала тот, где обмен получает больше людей, затем — с более высокими приоритетами. Это задача целочисленного линейного программирования (постановка задачи об обмене почек, kidney exchange). Её решает HiGHS (`scipy.optimize.milp`) с лимитом времени, и результат сравнивается с жадным выбором.

Обработчик запускается по расписанию (`MATCHING_INTERVAL_SEC`, по умолчанию раз в 10 минут), после каждой сохранённой заявки и после отмены обмена. Перед подбором он снимает предложения, на которые не ответили за `OFFER_TTL_HOURS` (48 часов).

## Запуск локально

```bash
python -m venv .venv
.venv/bin/pip install -r requirements-dev.txt   # Windows: .venv\Scripts\pip
.venv/bin/uvicorn app.main:app --reload
.venv/bin/pytest
```

Swagger UI откроется на http://127.0.0.1:8000/docs.

## Чем демо отличается от системы из концепции

| Концепция | Демо |
|---|---|
| PostgreSQL | хранение в памяти (`app/store.py`), те же сущности |
| Вход по одноразовому коду, токен | заголовок `X-User-Id` |
| Сервис подбора — отдельный контейнер, события через RabbitMQ | модуль в том же процессе, вызывается напрямую и по таймеру |
| Сервис уведомлений: ВКонтакте и email | журнал отправленных уведомлений (`GET /me/notifications`) |
